# DataCamp: Intermediate Python

## Description

This repository contains the exercises completed by Karl Sebastian V. Cuerdo for the Intermediate Python course on DataCamp. The exercises cover data visualization with Matplotlib, the dictionary data structure, and tabular data handling with pandas.

## Contents

| File | Topic |
|---|---|
| `histogramLesson.py` | Histograms with Matplotlib, using life expectancy data |
| `customizationLesson.py` | Customization of Matplotlib plots: axis labels, titles, and logarithmic scales |
| `dictionaryLesson.py` | Creating, accessing, and modifying dictionaries |
| `pandasLesson.py` | Building pandas DataFrames, setting row labels, and importing `cars.csv` |
| `cars.csv` | Dataset used in the pandas exercise |

## Requirements

Python 3 with Matplotlib and pandas.

```bash
pip install matplotlib pandas
```

## Usage

Each file is a standalone script and can be run on its own, for example:

```bash
python histogramLesson.py
```
